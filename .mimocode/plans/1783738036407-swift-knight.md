# 知识图谱导出功能

## 目标

在知识图谱弹窗（KnowledgeGraphModal）中添加导出按钮，支持 4 种格式：
- **SVG** — 矢量图，无损缩放
- **PNG** — 位图，方便分享
- **JSON** — 原始图谱数据（nodes + edges），供程序消费
- **Markdown** — 可读文本，展示节点和关系列表

## 改动范围

### 1. `client/src/components/KnowledgeGraphModal.jsx` — 主要改动

在 `.kg-modal-header` 的 `.kg-modal-actions` 区域添加导出下拉菜单按钮（与 MindMapModal 的 📥 导出按钮风格一致）。

#### 新增函数：

- **`handleExportSVG()`** — 从 `graphContainerRef` 中提取 `<svg>` 元素，序列化为字符串，创建 Blob 下载
  - 给 SVG 内联 CSS 样式（字体、背景色），确保导出后可读
  - 文件名：`{plan.name}.知识图谱.svg`

- **`handleExportPNG()`** — 将 SVG 绘制到 `<canvas>`，导出为 PNG
  - 使用 `XMLSerializer` + `Image` + `canvas.toBlob('image/png')`
  - 设置高 DPI（2x）以获得清晰图片
  - 文件名：`{plan.name}.知识图谱.png`

- **`handleExportJSON()`** — 直接导出 `graphData`（nodes + edges + inferredCount 等）
  - `JSON.stringify(graphData, null, 2)` 美化输出
  - 文件名：`{plan.name}.知识图谱.json`

- **`handleExportMarkdown()`** — 将图谱数据转为可读 Markdown
  - 格式：标题 + 节点列表（按阶段分组）+ 关系列表（按类型分组）
  - 包含节点属性（已完成/未完成、层级、难度）
  - 文件名：`{plan.name}.知识图谱.md`

#### UI 变更：

在 `kg-modal-actions` 的 🔄 按钮前增加一个导出按钮组（下拉菜单或直接并列按钮）：

```jsx
<div className="kg-export-group">
  <button className="btn-tiny" onClick={handleExportSVG} title="导出 SVG 矢量图">📥 SVG</button>
  <button className="btn-tiny" onClick={handleExportPNG} title="导出 PNG 图片">📥 PNG</button>
  <button className="btn-tiny" onClick={handleExportJSON} title="导出 JSON 数据">📥 JSON</button>
  <button className="btn-tiny" onClick={handleExportMarkdown} title="导出 Markdown 文档">📥 MD</button>
</div>
```

### 2. `client/src/styles/app.css` — 小改动

添加 `.kg-export-group` 样式：flex 布局，按钮紧凑排列，hover 时显示 tooltip。

### 3. 不需要后端改动

所有导出都是纯前端操作：
- SVG: 直接从 DOM 提取
- PNG: SVG → Canvas → Blob
- JSON: 前端已有 `graphData` state
- Markdown: 前端从 `graphData` + `plan` 构建

## 关键实现细节

### SVG 导出
```js
// 1. 从 DOM 获取 SVG 元素
const svgEl = graphContainerRef.current.querySelector('svg');
// 2. 克隆并内联关键样式
const clone = svgEl.cloneNode(true);
clone.setAttribute('xmlns', 'http://www.w3.org/2000/svg');
// 添加白色背景
const bg = document.createElementNS('http://www.w3.org/2000/svg', 'rect');
bg.setAttribute('width', '100%'); bg.setAttribute('height', '100%');
bg.setAttribute('fill', 'white');
clone.insertBefore(bg, clone.firstChild);
// 3. 序列化 → Blob → download
```

### PNG 导出（2x 高清）
```js
// 1. SVG → Data URL
const svgData = new XMLSerializer().serializeToString(svgEl);
const svgBlob = new Blob([svgData], {type:'image/svg+xml;charset=utf-8'});
const url = URL.createObjectURL(svgBlob);
// 2. 绘制到 canvas（2x 分辨率）
const img = new Image();
img.onload = () => {
  const canvas = document.createElement('canvas');
  canvas.width = img.width * 2;
  canvas.height = img.height * 2;
  const ctx = canvas.getContext('2d');
  ctx.scale(2, 2);
  ctx.fillStyle = 'white';
  ctx.fillRect(0, 0, img.width, img.height);
  ctx.drawImage(img, 0, 0);
  canvas.toBlob(blob => { /* download */ }, 'image/png');
};
img.src = url;
```

### Markdown 导出格式
```markdown
# 知识图谱 — {plan.name}

## 知识点（{n} 个）

### 阶段: {phaseName}
- {title} ✅（已学习）
- {title}（未学习）

## 关系（{m} 条）

### 包含关系
- {parent} → {child}

### 前置依赖
- {A} → {B}（前置依赖）

### 相关
- {A} ↔ {B}
```

## 验证方式

1. 打开前端，进入一个有知识点的学习计划
2. 点击"🕸️ 知识图谱"按钮打开弹窗
3. 等图谱渲染完成
4. 点击各导出按钮，验证：
   - SVG: 浏览器能正常打开，内容完整
   - PNG: 图片清晰，包含图谱内容
   - JSON: 包含 nodes 和 edges 数组，数据完整
   - Markdown: 格式正确，可读性强
5. 运行测试：`node --test --test-concurrency=1 --test-force-exit "__tests__/*.test.js"` 确保无回归
