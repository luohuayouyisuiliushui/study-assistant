# Plan: 改善前端页面紧凑感

## 问题分析

当前页面整体视觉偏紧凑，主要体现在以下几个方面：

1. **Header 太窄**：`py-2.5` 使得顶部栏高度不足，与内容区分隔不够明显
2. **内容区 padding 偏小**：TopicDetail、PlanView 等主内容区使用 `px-8`，在宽屏上内容贴近边缘
3. **Topic 列表项过于密集**：`px-4 py-2.5` + `space-y-1` 使得知识点列表行距太小
4. **统计卡片区域拥挤**：`p-4` 在 4 列网格中显得紧凑
5. **Section 间缺乏呼吸感**：分析面板、测验、练习题等区域内部 padding 偏小（`p-4`）

## 修改方案

### 1. Header 加高（App.jsx:110）

```diff
- className='flex items-center justify-between border-b bg-card px-6 py-2.5'
+ className='flex items-center justify-between border-b bg-card px-6 py-3'
```

### 2. 主内容区加大侧边距（TopicDetail.jsx:600, PlanView.jsx:326）

+ TopicDetail: className='w-full max-w-4xl px-10 py-8 space-y-6'
