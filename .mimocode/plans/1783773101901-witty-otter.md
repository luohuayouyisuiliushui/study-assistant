# Plan: 引入 React Router 替换 useState 跳转

## 概要

将当前基于 `useState` 的条件渲染跳转改为基于 URL 的路由，使浏览器地址栏随页面变化、后退按钮正常工作。

## 目标路由

| 路径 | 组件 | 说明 |
|---|---|---|
| `/` | PlanList | 计划列表首页 |
| `/plan/:planId` | PlanView | 单个计划详情 |
| `/plan/:planId/topic/:topicId` | TopicDetail | 知识点详情 |
| `/profile` | UserProfile | 学习画像 |

## 改动文件清单

### 1. `client/src/main.jsx`
- 安装 `react-router-dom`
- 在 `<App />` 外层包裹 `<BrowserRouter>`

```jsx

createRoot(document.getElementById('root')).render(
  <StrictMode>
    <ThemeProvider>
      <BrowserRouter>
        <App />
      </BrowserRouter>
    </ThemeProvider>
  </StrictMode>
)
```

### 2. `client/src/lib/plan-context.jsx`（新建）
- 创建 `PlanContext` 提供全局 plan 状态，避免 prop drilling
- 导出 `PlanProvider` 和 `usePlan` hook

```jsx
import { createContext, useContext, useState, useCallback, useRef, useEffect } from 'react'
import api from '../api'

const PlanContext = createContext(null)

export function PlanProvider({ children }) {
  const [plans, setPlans] = useState([])
  const [currentPlan, setCurrentPlan] = useState(null)

  const refreshPlans = useCallback(async () => {
    try { const d = await api.listPlans(); setPlans(d.plans) } catch {}
  }, [])

  useEffect(() => { refreshPlans() }, [refreshPlans])

  const refreshPlan = useCallback(async (planId) => {
    if (!planId) { setCurrentPlan(null); return }
    try { const d = await api.getPlan(planId); setCurrentPlan(d.plan) } catch { setCurrentPlan(null) }
  }, [])

  return (
    <PlanContext.Provider value={{ plans, setPlans, currentPlan, setCurrentPlan, refreshPlans, refreshPlan }}>
      {children}
    </PlanContext.Provider>
  )
}

export function usePlan() {
  const ctx = useContext(PlanContext)
  if (!ctx) throw new Error('usePlan must be used within PlanProvider')
  return ctx
}
```

### 3. `client/src/App.jsx`（大幅重写）
- 移除所有 `useState` 路由状态（`currentPlanId`, `showProfile`, `activeTopicId`）
- 移除 `goToList`, `handleGenerate`, `handleRemoveTopic` 等导航相关函数
- 用 `<Routes>` + `<Route>` 替换条件渲染
- Header 改为用 `useLocation()` 判断当前路由，用 `useNavigate()` 处理返回
- 数据操作函数（`handleCreatePlan`, `handleDeletePlan` 等）保留但通过 context 共享
- Plan 数据轮询逻辑上提至 context 或保留在 App 中通过 context 操作

**核心结构：**

```jsx
import { Routes, Route, useNavigate, useLocation, Navigate } from 'react-router-dom'
import { PlanProvider, usePlan } from '#/lib/plan-context.jsx'

function AppContent() {
  const navigate = useNavigate()
  const location = useLocation()
  const { plans, setPlans, currentPlan, setCurrentPlan, refreshPlans, refreshPlan } = usePlan()

  // Header 返回按钮逻辑
  const showBack = location.pathname !== '/' && !location.pathname.startsWith('/profile')

  const goToList = () => {
    setCurrentPlan(null)
    navigate('/')
  }

  return (
    <div className='flex flex-col h-screen bg-background'>
      <header> ... </header>
      <main className='flex-1 overflow-auto flex justify-center'>
        <Routes>
          <Route path="/" element={
            <PlanList
              plans={plans}
              onCreate={handleCreatePlan}
              onImport={handleImportPlan}
              onSelect={(id) => navigate(`/plan/${id}`)}
              onDelete={handleDeletePlan}
            />
          } />
          <Route path="/plan/:planId" element={
            <PlanViewWrapper onGenerate={(topicId) => navigate(`/plan/${params.planId}/topic/${topicId}`, { state: { fromPlan: true } })} />
          } />
          <Route path="/plan/:planId/topic/:topicId" element={
            <TopicDetailWrapper onSelectTopic={(id) => navigate(`/plan/${params.planId}/topic/${id}`, { replace: true })} />
          } />
          <Route path="/profile" element={<UserProfile onBack={() => navigate('/')} />} />
          <Route path="*" element={<Navigate to="/" replace />} />
        </Routes>
      </main>
    </div>
  )
}
```

**PlanViewWrapper**：从 URL params 读取 `planId`，通过 `refreshPlan(planId)` 获取数据，传给 `PlanView`。

**TopicDetailWrapper**：从 URL params 读取 `planId` + `topicId`，从 context 的 `currentPlan` 中找到对应 topic，传给 `TopicDetail`。

**关键数据流：**
- `handleCreatePlan` → `api.createPlan` → `refreshPlans()` → `navigate(\`/plan/${id}\`)`
- `handleDeletePlan` → `api.deletePlan(id)` → `refreshPlans()` → 如果是当前 plan 则 `goToList()`
- `handleImportPlan` → `api.importPlan` → `refreshPlans()` → `navigate(\`/plan/${id}\`)`
- Plan 轮询：AppContent 中 `useEffect` 监听 `params.planId`，定时调 `refreshPlan(planId)`

### 4. `client/src/components/TopicDetail.jsx`
- `onBack` 改为 `useNavigate()` 调用 `navigate(\`/plan/${planId}\`)`（如果 prop 不传）
- `handleNavigateToTopic` 直接用 `navigate(\`/plan/${planId}/topic/${id}\`, { replace: true })`
- `doComplete` 中的 `onBack()` 改为 `navigate(\`/plan/${planId}\`)`

实际上保持 `onBack` / `onSelectTopic` 作为 props 从 wrapper 传入更简洁——wrapper 内部用 `useNavigate`。
